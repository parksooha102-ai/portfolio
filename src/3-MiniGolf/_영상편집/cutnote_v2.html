실시간으로 녹화하므로 영상 길이만큼 걸려요. 이 탭을 화면에 띄워 두세요.

나눠 녹화한 영상을 한꺼번에 열거나 끌어다 놓으면 여기에 이름순으로 모여요. 메인 라인이 비어 있으면 이 순서대로 바로 이어 붙입니다.

크기나 비율이 다른 영상은 비율을 유지한 채 가운데에 맞춰져요. 메인 라인의 구간 순서는 구간을 선택한 뒤 속성 탭에서 바꿀 수 있어요.

템플릿을 고르고 [삽입]을 누르면 재생 위치에 들어가요. 문구는 속성 탭에서 바꿀 수 있어요.

또는 템플릿 JSON을 붙여넣으세요.

템플릿 형식 보기

좌표와 크기는 화면 비율(0~1)이고, 글자 크기와 모서리 반경은 화면 높이 대비 비율이에요. 문구 안의 {{이름}}은 params 값으로 바뀝니다. Claude에게 이 형식으로 만들어 달라고 하면 그대로 붙여넣어 쓸 수 있어요.

{
  "id": "callout",
  "name": "콜아웃 박스",
  "params": { "text": "여기를 클릭하세요" },
  "duration": 3,
  "animation": { "in": "rise", "out": "fade", "dur": 0.3 },
  "elements": [
    { "type": "rect", "x": 0.60, "y": 0.12, "w": 0.32, "h": 0.09,
      "fill": "#FFD24D", "radius": 0.012 },
    { "type": "text", "x": 0.76, "y": 0.165, "text": "{{text}}",
      "size": 0.034, "weight": 700, "color": "#1A1A1A",
      "align": "center" }
  ]
}

animation.in : none | fade | slide | rise
animation.out: none | fade
rect: x y w h fill opacity radius stroke strokeWidth
text: x y text size weight color font align opacity

편집 상태 전체가 이 JSON에 담겨 있어요. Claude에게 붙여넣고 "'로그인 실패' 라벨 구간을 잘라내고 자막 문구를 다듬어줘"처럼 요청한 뒤, 돌려받은 JSON을 붙여넣고 [적용]을 누르세요. 시간 단위는 초예요. JSON이 길면 [요약 복사]로 구조만 먼저 보여줘도 돼요.

브라우저 에이전트용 API

Claude in Chrome 같은 브라우저 에이전트는 페이지의 editor 객체를 바로 호출할 수 있어요. 먼저 editor.describe()로 구조를 읽고, 전체 목록은 editor.help()로 볼 수 있습니다.

editor.describe()
editor.addLabel({ start: 42, end: 51, text: "로그인 실패", note: "잘라낼 것" })
editor.cutLabel("로그인 실패")
editor.insertMedia("m2", 30)
editor.moveSegment(2, -1)
await editor.frameAt(10)   // 그 시점 화면 (JPEG data URL)
00:00.00 / 00:00.00
